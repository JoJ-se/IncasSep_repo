# IncasSep_repo

Презентация-документ Incas по ГЕО: Турция, Китай, РФ локальный рынок (НСПК QR э-ком / OCT).

## Содержание

Единый HTML-файл [`index.html`](./index.html), оформленный как презентация (слайды), на русском языке:

1. **Турция** — статус каналов за август 2026, средневзвешенная ставка, план на сентябрь–октябрь
2. **Китай** — payout/payin каналы, экономика нового платёжного канала, цели к концу октября
3. **РФ локальный рынок (НСПК QR э-ком / OCT)** — раздел-плейсхолдер, ожидает исходные данные

## Источник данных

Страницы «Турция» и «Китай» — сжатая версия данных из репозитория [`incas-geo-expansion-pack`](https://github.com/JoJ-se/incas-geo-expansion-pack) (там же — полная детализация, сырые данные в CSV и расчёты).

Страница «РФ локальный рынок» пока не заполнена реальными цифрами — для неё нужны:
- Каналы / провайдеры (НСПК QR для э-кома, OCT и др.)
- Текущий статус каждого — Live / в интеграции / план
- Ставки PayIn / PayOut, %
- Реальные или целевые объёмы
- Лимиты, комментарии, сроки запуска
